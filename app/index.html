Gestion d'absence

Établissement & année scolaire

Code de l'établissement, académie, direction provinciale, année et semestres : à saisir une seule fois.

Fermeture de l'établissement

Vacances, examens, fêtes religieuses ou nationales, réunion… : aucune séance n'est assurée sur la période et les absences prises pendant ces séances ne comptent pas dans les statistiques.

Fermetures enregistrées

Annulation de séances

Annuler une séance précise (examen, réunion, séance non assurée) : elle ne compte pas dans les statistiques. Les séances annulées apparaissent aussi sur les Dashboards (directeur et surveillant).

Annulations enregistrées

Importation des fichiers

Importer les listes MASSAR

Uploadez un ou plusieurs fichiers Excel MASSAR (export_notesCC) : tous les fichiers et toutes leurs feuilles (classes) sont importés en une seule fois. Colonnes : C = code MASSAR, D = nom arabe, E = nom français.

Cliquez ou glissez un ou plusieurs fichiers ici

.xlsx uniquement

Importer les tableaux de services

Tableaux de service des professeurs

Un fichier par professeur (ou un fichier à plusieurs feuilles) : la grille des jours et des créneaux, puis la liste « matière / professeur ». Un professeur dont la matière correspond à un compte est relié automatiquement ; plus de 20 h de service est signalé.

Cliquez ou déposez les tableaux de service (.xlsx)

Importer les tableaux d'élèves

Tableaux des élèves

Fichiers des élèves par classe (une feuille par classe, ou une colonne « classe ») avec le code MASSAR et le nom. Un élève dont le code MASSAR est déjà présent n'est pas dupliqué.

Cliquez ou déposez les tableaux des élèves (.xlsx)

Doublons d’élèves

Un élève dont le code MASSAR est déjà présent n’est jamais dupliqué à l’import. Si un ancien import a créé des doublons, cet outil les retrouve et les fusionne en gardant l’historique.

Codes MASSAR manquants

Un élève sans code ne peut être ni reconnu, ni proposé comme « sorti » lors d’un import : il resterait mélangé aux vrais élèves. Cet outil retrouve ces élèves et les liste, classe par classe (touche une ligne pour ouvrir sa fiche). Rien n’est modifié.

Classes existantes

Cliquez sur une classe pour voir la liste de ses élèves.

Surveillants

Ajouter un surveillant, corriger son nom, définir son mot de passe. Ses identifiants de connexion sont générés avec ceux des enseignants.

Absence d'un surveillant : la période est enregistrée et listée ci-dessous.

Absences enregistrées

Enseignants

Corriger le nom d'un enseignant, définir ou générer son mot de passe : la modification s'applique partout, y compris dans l'historique des signalements.

Absence d'un enseignant : toutes ses séances de la période sont annulées (jours et heures déduits de son tableau de service) et ne comptent pas dans les statistiques.

Identifiants du personnel
